## 🚀 Overview
AI Career Copilot is a Streamlit-based, Gemini AI-powered career assistant that analyzes resumes, checks ATS compatibility, matches resumes against job descriptions, and generates tailored career documents — all through an interactive dashboard.

It simulates a real-world **Applicant Tracking System (ATS)** while adding AI-generated content and export tools on top, so job seekers can both diagnose and fix their resume in one place.

---

## 🎯 Problem Statement
Manual resume screening is time-consuming, inconsistent, and not scalable. Job seekers rarely know how their resume performs against an ATS or a specific job description before they apply.

---

## 💡 Solution
AI Career Copilot combines resume parsing, ATS analysis, job description matching, and Gemini-powered content generation into a single dashboard — helping users understand where their resume stands and generate the material they need to improve it.

## 📦 Installation

```bash
git clone https://github.com/Shrutii008/AI_Career_Copilot.git
cd AI_Career_Copilot
pip install -r requirements.txt
```

Create a `.env` file:

```env
GEMINI_API_KEY=YOUR_API_KEY
EMAIL_ADDRESS=YOUR_EMAIL
EMAIL_APP_PASSWORD=YOUR_APP_PASSWORD
```

## ▶️ Run the Application

```bash
streamlit run app.py
```
